Core Architecture & Rubrics

📐

Linear Algebra Scoring

Computes composite academic profiles using weighted dot products of student feature vectors against subject credits and mid/external exam weights.

Vector Dot Product Weights Matrix
⚡

Custom Sorting Engine

Ranks cohort records using a pure Python QuickSort algorithm featuring median-of-three pivot selection to guarantee efficient O(N log N) execution.

QuickSort Divide & Conquer
🛡️

Database Fallback Engine

Integrates MongoDB via PyMongo with an automated CSV file fallback system, guaranteeing full functionality during local offline evaluations.

MongoDB Atlas CSV Fallback 75% Alerting
🤖

AI/ML Analytics Layer

Segments cohorts into risk categories via K-Means Clustering and fits Linear Regression models to predict Semester 1-2 growth curves.

K-Means Linear Regression Scikit-Learn

Mathematical Framework

Students are evaluated using a five-dimensional feature vector mapped onto subject credit scales:

Score_i = S_i · W = Σ (S_i[j] × W[j])

Where W (Weight Vector) is defined as:

W = [0.25 (Attendance), 0.15 (Mid 1), 0.15 (Mid 2), 0.35 (External), -0.10 (Backlogs)]
